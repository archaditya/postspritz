# PostSpritz Brand Kit

A flat, friendly visual identity built around warm orange, charcoal, and warm white.

## Palette
- Primary orange: `#FF5A1F`
- Deep orange: `#E84712`
- Ink: `#17191C`
- Warm white: `#FAF9F6`
- Muted gray: `#73777D`
- Tagline: **Create once. Spritz everywhere.**

## Files
- `logos/svg/`: horizontal, dark-background, stacked, and icon-only SVG logos.
- `favicons/`: SVG, PNG 16/32/48, and ICO favicon.
- `app-icons/`: transparent icon sizes from 16px to 512px and app icon variants.
- `social/`: 1200×630 social sharing / Open Graph preview.
- `docs/`: brand guidelines and web integration snippets.
- `preview/`: quick brand preview board.

## Recommended usage
- Website header: `logos/svg/postspritz-logo-horizontal.svg`
- Dark surfaces: `logos/svg/postspritz-logo-horizontal-dark.svg`
- Browser favicon: `favicons/favicon.ico` or `favicons/favicon.svg`
- PWA icon: `app-icons/postspritz-app-light-512.png`
- Open Graph image: `social/postspritz-social-preview-1200x630.png`

The SVGs are editable vector artwork. Review them in your actual product UI before launch, especially at very small sizes. Trademark and domain clearance are separate from this asset pack.
