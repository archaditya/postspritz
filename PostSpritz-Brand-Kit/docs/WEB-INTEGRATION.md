# Web integration

Add to the HTML `<head>`:

```html
<link rel="icon" href="/favicons/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/favicons/favicon.ico" sizes="any">
<link rel="icon" href="/favicons/favicon-32x32.png" type="image/png" sizes="32x32">
<link rel="apple-touch-icon" href="/app-icons/postspritz-app-light-512.png">
<meta property="og:title" content="PostSpritz — Create once. Spritz everywhere.">
<meta property="og:description" content="Publish and schedule content across your social platforms.">
<meta property="og:image" content="https://YOUR_DOMAIN/social/postspritz-social-preview-1200x630.png">
<meta name="twitter:card" content="summary_large_image">
```

Replace `YOUR_DOMAIN` with the verified production domain.
